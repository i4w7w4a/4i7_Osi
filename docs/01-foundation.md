# Основа и дочерняя система

4i7 — общая исследуемая рамка. 4i7_Osi — отдельное прикладное развитие для будущей оркестрации. Дочерняя реализация не заменяет философскую основу и не доказывает её.

- Версия этого документационного скелета: 0.1.0-draft. Она не означает версию готового программного продукта или утверждение всей философии.

- Обновление основы не принимается автоматически. Сначала сравнение, issue, решение, затем PR с журналом изменений.
- Если разрешённого публичного источника нет, не выдавать внутреннюю ссылку за проверяемую для внешнего читателя. Отмечать ограничение явно.

Названия столпов — рабочая карта. Конкретные механизмы оркестратора остаются гипотезами. Успешный тест прикладного механизма сам по себе не устанавливает истинность метафизических утверждений.
